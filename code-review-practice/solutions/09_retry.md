# Разбор: 09_retry.py

Декоратор ретраев. Опасен именно тем, что выглядит нормально.

1. **После исчерпания попыток возвращается `None`** (строки 11–20). Когда все `times`
   попыток провалились, цикл заканчивается и `wrapper` неявно возвращает `None` — вместо
   того чтобы **пробросить последнее исключение**. Вызывающий код думает «функция отработала,
   вернула None», и баг всплывает где-то далеко. Для `fetch_data`/`charge_card` это значит:
   платёж не прошёл, а наверх ушло `None` как «успех». Фикс: после цикла `raise` последнего
   исключения (сохранять его и перевыбросить, либо `raise` внутри `else`).

2. **Ретрай неидемпотентной операции** (`charge_card`, строки 30–32). Списание с карты
   ретраится вслепую. Если запрос дошёл до шлюза и **прошёл**, но ответ потерялся (таймаут),
   ретрай спишет деньги **повторно**. Ретраить можно только идемпотентные операции или
   операции с idempotency-key. Это концептуальный баг применения декоратора, не только кода.

3. **Ловится `Exception` целиком** (строка 15). Ретраятся и `ValueError`, и `KeyError`,
   и баги в самой функции — которые ретрай никогда не починит, только замедлит отказ в N раз.
   Ретраить надо конкретные (обычно сетевые/временные) исключения.

4. **Фиксированная задержка без backoff/jitter** (строка 18). `time.sleep(delay)` с
   постоянным интервалом. При массовых сбоях все клиенты ретраят синхронно — «стадо».
   Нужен экспоненциальный backoff + jitter.

5. **`time.sleep` даже после последней неудачной попытки** (строки 17–18). На последней
   итерации всё равно спим `delay` секунд, хотя ретраить уже не будем — лишняя задержка.

6. Декоратор не сохраняет метаданные обёрнутой функции — нужен `@functools.wraps(func)`.

7. `print` для логов ретраев — в проде должен быть `logging`.

8. Нет предела на суммарное время; при большом `times*delay` можно висеть очень долго.

9. **Нет аннотаций типов** (`retry`, `decorator`, `wrapper`). Типизировать декоратор с
   параметрами руками муторно, но параметры хотя бы просятся: `times: int = 3`,
   `delay: float = 1`. Для сохранения сигнатуры обёрнутой функции — `ParamSpec`/`TypeVar`
   (вместе с `functools.wraps` из п.6).

**Итого:** тихий возврат `None` при провале (он превращает отказ в ложный успех) +
ретрай списания денег. Мораль: «выглядит рабочим» ≠ «корректно обрабатывает провал»;
и ретрай — только для идемпотентного.
