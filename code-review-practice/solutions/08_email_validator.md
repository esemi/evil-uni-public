# Разбор: 08_email_validator.py

Валидатор email. Баги порядка операций + мелкие питон-запахи.

1. **`normalize_email` падает на невалидных данных, но порядок в `process_emails` спасает —
   проверь внимательно** (строки 25–26). Сам `normalize_email` делает `email.split("@")`
   в `name, domain = ...` — если `@` нет или их несколько, будет `ValueError`. В `process_emails`
   перед ним стоит `validate_email`, так что напрямую баг не стреляет. Но `normalize_email`
   публичная и может быть вызвана отдельно — тогда падает. Хрупкий контракт.

2. **`normalize` мутирует до валидации регистра/пробелов рассинхрон** — тоньше: `validate_email`
   проверяет **сырую** строку, а `normalize_email` сначала делает `.strip()` и `.lower()`.
   Если на вход пришло `"  a@b.com  "` (с пробелами) — `validate_email` увидит пробелы как
   часть name/domain и всё равно вернёт True (пробел не запрещён явно), а нормализация их
   срежет. Валидация и нормализация работают с разными версиями строки — источник рассинхрона.
   Правильнее нормализовать, *потом* валидировать.

3. **`validate_email` не проверяет пробелы/лишние символы** в name и domain. `"a b@c.com"`,
   `"a@ c.com"` пройдут. Валидация email самописным сплитом всегда дырявая — для базовой
   проверки лучше готовая либа (`email-validator`) или хотя бы более строгий набор правил.

4. **`domain` без TLD-логики**: `"a@b."` — есть точка, но домен заканчивается точкой,
   пройдёт валидацию (`"." in domain` True). Краевые случаи не покрыты.

5. `email == None` → должно быть `email is None` (сравнение с None только через `is`).

6. `if validate_email(e) == True:` → просто `if validate_email(e):`. Сравнение булева
   с `True` — антипаттерн.

7. `len(name) == 0` → питоничнее `if not name`.

8. `if "@" not in email` избыточен: следующая проверка `len(parts) != 2` уже это ловит.

**Итого:** главное — поймать рассинхрон «валидируем сырое, нормализуем изменённое» и
порядок операций, плюс набор питон-идиом (`is None`, `== True`). Валидатор email руками —
сам по себе повод для комментария на ревью.
