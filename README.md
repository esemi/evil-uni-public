# unicorn-career-consulting 🦄🎓

Методички «единорожьего карьерного консалтинга» для подготовки к собеседованию на **Python-backend разработчика**.

Это не курс и не книга, а сжатые конспекты тем + практические задачи-заготовки.
Идея простая: берёшь список тем, прогоняешь каждую через голову (и при желании через
ChatGPT), а потом закрепляешь руками на практических задачах. Всё разбито на порции
«на один день», чтобы готовиться можно было маленькими подходами.

## Оглавление

| Блок | О чём |
|------|-------|
| [Теория](theory/README.md) | Сжатые конспекты тем, разбитые по разделам: язык и внутренности, backend-инженерия, system design, лайвкод, AWS, харды для резюме. |
| [Практика](practice/README.md) | Задачи-заготовки с дырами (`raise NotImplemented`, пустые классы, `# todo`) — закрываешь их руками. Разбита по блокам зеркально теории: Python и программная инженерия. |
| [Тренажёр код-ревью](code-review-practice/README.md) | Отдельный трек на навык чтения и ревью чужого Python-кода: модули по возрастанию сложности, «грязные» файлы с багами + эталонные разборы. |
