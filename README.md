# evil-uni-public 🎓😈

Методички «университета зла» для подготовки к собеседованию на **Python-backend разработчика**.

Это не курс и не книга, а сжатые конспекты тем + практические задачи-заготовки.
Идея простая: берёшь список тем, прогоняешь каждую через голову (и при желании через
ChatGPT), а потом закрепляешь руками на практических задачах. Всё разбито на порции
«на один день», чтобы готовиться можно было маленькими подходами.

## Что внутри

### Практика (`practice/`)

Задачи-заготовки — в них специально оставлены дыры (`raise NotImplemented`, пустые
классы, `# todo`), твоя цель — их закрыть.

| Файл | Задачи |
|------|--------|
| [`practice/python_basic.py`](practice/python_basic.py) | Контекстные менеджеры (sync/async), простые числа через треды vs процессы, долгие ожидания через asyncio, `__hash__` для наследника `dict`, `__slots__` для экономии памяти. |
| [`practice/pytest.py`](practice/pytest.py) | Функции `example_*` (в т.ч. async-запрос по HTTP и функция с `time.sleep`) — надо написать на них тесты на `pytest`, включая моки. |
| [`practice/indexing.sql`](practice/indexing.sql) | Песочница PostgreSQL (генерятся таблицы `employees`/`sex`) + запросы, которые нужно оптимизировать индексами. Смотри `EXPLAIN (ANALYZE)`. |

## Как этим пользоваться

1. **Оцени пробелы.** Пробегись по `python-cv-skills.md` — что из хардов уже знаешь, что нет.
2. **Учи теорию порциями.** Открывай любой из `*-one-day.md` и иди по темам сверху вниз.
   Метод из `python-backend-one-day.md`:
   - задаёшь ChatGPT контекст («готовлюсь к собесу, буду присылать темы, отвечай brief-выжимкой»);
   - шлёшь каждую тему, читаешь выжимку, непонятное — просишь раскрыть глубже;
   - что осталось мутным — записываешь и потом добиваешь с ментором/по ссылкам.
3. **Закрепляй руками.** После блока теории иди в `practice/` и закрывай соответствующие задачи:
   - Python-темы → `python_basic.py`;
   - тесты и моки → `pytest.py` (запускай через `pytest`);
   - индексы и оптимизация запросов → `indexing.sql` (подними локальный PostgreSQL, залей песочницу, гоняй `EXPLAIN ANALYZE`).
4. **System design и архитектура** — отдельным подходом по `system-design-interview-basics.md`
   и `architectural-one-day.md`, лучше уже с наработанной теорией под капотом.
